# Manual downloads (optional)

Files placed here are picked up automatically by `Main.py build-data`.

| File name | Why | Where to get it |
|---|---|---|
| `countypres_2000-2024.csv` | County presidential returns 2000-2024 (otherwise the 2008-2024 GitHub mirror is used) | https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/VOQCHQ (accept the guestbook, download the original CSV) |
| `2020_USRC_Summaries.xlsx` | Only if the automatic download from usreligioncensus.org fails | https://usreligioncensus.org/node/1639 |
| `2010_USRC_County.csv` | Adds a 10-year change in religious adherence (columns `FIPS`, `TOTRATE`) | ARDA study RCMSCY10, https://www.thearda.com/us-religion/census/congregational-membership |
